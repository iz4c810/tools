# Tools Repo

## About
This repository is ment to contain ALOT of tools for both windows and linux, in not including macos because i dont think most people who want these tools will want to be on macos

## How To Get A Specific Tool
if you are on windows you need to go to Windows/{TOOL NAME}/src.{tool lang, e.g. ps1}

if you are on linux you need yo go to Linux/{TOOL NAME}/src.{tool lang, e.g. sh}

## MacOS Users!!!
If you are actually using MacOS you need to have a translator for the shell scripts, or a compiler for the .cpp and .c files that will be on here
